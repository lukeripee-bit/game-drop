How to install SM64 Co-op Deluxe

  1. Download the SM64 Co-op ZIP and the SM64 ROM ZIP below.
  2. Right-click each ZIP and choose Extract All.
  3. Open the extracted SM64 Co-op folder and run sm64coopdx.exe.
  4. When the game asks for a ROM, drag the extracted .z64 file onto the game window.
  5. Wait for setup to finish, then open the game and choose a multiplayer option to host or join.

How to use Blur AutoClicker

  1. Download the portable ZIP, then right-click it and choose Extract All.
  2. Open the extracted folder and run BlurAutoClicker.exe. No installation or administrator access is required.
  3. If the app reports that WebView2 is missing, run the included MicrosoftEdgeWebview2Setup.exe.
  4. Because this app is unsigned, keep Windows Security enabled and only continue if you trust the file.
